# Topics, past papers, class register and learning gaps (for the teacher)

## 1. Topics (units)
Sidebar → **Topics**. Choose the grade and enter the units in the order you teach them, e.g. unit 3 "Matter" / "පදාර්ථ". The list is shared by all three branches.
Then, when you post notes, set a quiz, add a question or set homework, choose the unit in the **Topic (unit)** box. A single question can have its own unit; otherwise it counts under the quiz's unit.
**Hide** removes a unit from the pickers; work already tagged keeps it.

## 2. Past papers
Sidebar → **Past papers** → **Add a past paper**: grade, year, paper type (term test, model paper…), medium, the paper, and optionally the marking scheme.
- Students of that grade see it under **Past papers** once this month's fee is paid.
- The marking scheme stays hidden until you press **Release marking scheme**, for example after the class has tried the paper.
- Upload only papers you are allowed to share.

## 3. Class register and absence alerts
Teaching → a class → **Register** (or Attendance → Class register). Students who scanned the QR code are already present. Mark the rest; **Mark everyone not marked as absent** does it in one click. Then **Save register**.
For each student marked absent today or yesterday, the family gets **one** alert:
- a notice in the parent portal (and the student's)
- a WhatsApp message prepared in the message log for the office to send

Saving again, or correcting the mark, does not alert twice. Registers for older dates are saved without alerts.

## 4. Learning gaps
Teaching → a class → **Learning gaps**:
- **By topic**: the class average per unit, hardest first, with the students below 50%
- **By student**: each student's overall mark and weakest unit
- **Questions most often wrong**: needs at least three marked answers
- **Work not done**: who did not sit a quiz or hand in homework after the deadline

The numbers come from marked work only: each student's latest quiz attempt (unanswered questions count as zero), and homework you have marked. Answers still waiting for marking are left out.
